Socialgram

UI complete · Firebase integration in progress

A social media application inspired by Instagram, built with React Native, Expo and TypeScript. It currently runs on mock data while Firebase Authentication and Firestore are being integrated.

  • Home feed with stories, post cards, like and save, and pull to refresh
  • Gestures: double-tap to like with an animated heart, long-press options, pinch to zoom
  • Profile screen with stats, highlights, posts grid and Posts/Saved tabs
  • Login screen with validation, show/hide password, loading and error states
  • Navigation with Expo Router and a custom bottom bar

CareerPilot

Full-stack GenAI app · Working demo

An AI career assistant built with React, Node.js and the Gemini API. It scores a resume against a job description and runs an interactive AI mock interview, with the API key kept safely on the backend.

  • Resume Analyzer: match score, strengths, missing skills and improved bullet points from structured JSON output
  • Mock Interviewer: multi-turn chat that asks tailored questions and gives feedback on each answer
  • Secure backend: Express API proxy so API keys never reach the browser
  • Reliability: automatic retry and model fallback when the AI service is busy
  • UI: responsive glassmorphism design with a tabbed layout
